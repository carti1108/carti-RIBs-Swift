### ADR-0003 생명주기 타입을 @MainActor로 격리한다
- 상태: 채택
- 날짜: 2026-11-13
- 배경: RIBs는 생명주기 메서드가 메인 스레드에서 불린다고 가정한다. KMP는 런타임 메인 스레드 검사(주입식)로 지켰다. Swift 6는 이를 컴파일 시점에 강제할 수 있다.
- 결정: Interactor, Router, Worker, Builder, Component, Presenter와 관련 프로토콜을 모두 `@MainActor`로 둔다. 런타임 스레드 검사와 내부 락은 두지 않는다. `RibState`·`RibValue`는 값 타입이고 `Sendable`이다.
- 고려했던 대안:
  (1) KMP처럼 런타임 검사: 위반을 실행해야만 알 수 있어 기각했다.
  (2) 커스텀 글로벌 액터: UI 프레임워크와 메인 스레드 공유가 필요해 이점이 없어 기각했다.
  (3) 락으로 스레드 안전하게: 원본 가정과 다르고 복잡도만 늘어 기각했다.
- 결과: 다른 액터에서 생명주기를 부르면 컴파일 오류가 난다. 테스트는 `@MainActor`에서 돌린다.
- 관련: ADR-0002
